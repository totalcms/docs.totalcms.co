Total CMS is a flat-file PHP content management system for people who build websites: site builders, developers, agencies, and freelancers. Content lives as JSON on disk, templates use Twig, and every operation in the admin is also a REST endpoint. It runs on any PHP host without a database.

These docs cover the whole system, from installing your first site to writing extensions. New here? Start with the [welcome guide](/get-started/welcome). Looking for a specific filter, field, or setting? Use the search box at the top of the page.
